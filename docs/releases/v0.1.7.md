## v0.1.7

### English

#### Added
- Add readable `[MATCH]` console output for every matched response, showing the matched input combination, final rendered URL, status, size, word count, line count, and elapsed time.
- Mirror matched results to `stderr` when `-o` writes JSONL, CSV, or console output to a file, so operators can see hits while preserving structured output files.
- Add richer Unix/Linux file descriptor planning that accounts for worker concurrency, DNS concurrency, output files, and keep-alive target pools.

#### Changed
- Update the README output documentation with the new `[MATCH]` line format and file-output mirroring behavior.
- Update the file descriptor guidance to recommend the exact `ulimit -n` value printed by startup checks.
- Bump the package version to `0.1.7`.

#### Verification
- `cargo fmt --check`: passed.
- `cargo test`: 69 passed.

### 中文

#### 新增
- 为每个命中的响应增加可读的 `[MATCH]` console 输出，显示命中的输入组合、最终渲染 URL、状态码、响应大小、单词数、行数和耗时。
- 当 `-o` 将 JSONL、CSV 或 console 输出写入文件时，同步把命中结果镜像打印到 `stderr`，便于运行过程中直接看到命中，同时保留结构化结果文件。
- 增强 Unix/Linux 文件描述符规划，估算时纳入 worker 并发、DNS 并发、输出文件，以及 keep-alive 目标连接池。

#### 变更
- 更新 README 输出文档，补充新的 `[MATCH]` 行格式和文件输出时的终端镜像行为。
- 更新文件描述符建议，按启动检查打印的精确 `ulimit -n` 值进行配置。
- 将包版本提升到 `0.1.7`。

#### 验证
- `cargo fmt --check`：通过。
- `cargo test`：69 个测试通过。
