## v0.2.2

### English

#### Fixed
- Keep readable `[MATCH]` lines visible while the main progress bar is active. File-output mirror lines now go through a progress-aware writer that suspends dynamic progress rendering before printing the match line.
- Flush JSONL, CSV, and console output files after every matching record so results are available while a scan is still running instead of only after final shutdown.

#### Changed
- Expand `.gitignore` coverage for local Codex/agent state, Codegraph metadata, build artifacts, and common scan output files.
- Remove already-tracked local metadata directories and the obsolete technical design draft from the repository index so they are not uploaded again.
- Update the English and Chinese version badges to `0.2.2`.
- Bump the package version to `0.2.2`.

#### Verification
- `cargo fmt --check`: passed.
- `cargo test`: passed, 97 tests.
- `cargo build --release`: passed.
- Local runtime check: with the process still running after a first hit, `result.jsonl` already contained one flushed JSONL record.

### 中文

#### 修复
- 修复主进度条刷新时可能看不到 `[MATCH]` 命中行的问题。文件输出的终端镜像现在会经过进度条感知 writer，在打印命中行前暂停动态进度渲染。
- JSONL、CSV 和 console 文件输出现在每写入一条命中记录都会立即 flush，扫描未结束时也能实时读取结果，而不是等最终退出才落盘。

#### 变更
- 扩展 `.gitignore`，覆盖本地 Codex/agent 状态、Codegraph 元数据、构建产物和常见扫描输出文件。
- 从仓库索引中移除已被跟踪的本地元数据目录和旧技术设计草稿，避免再次上传。
- 将中英文版本徽章更新为 `0.2.2`。
- 将包版本提升到 `0.2.2`。

#### 验证
- `cargo fmt --check`：通过。
- `cargo test`：通过，97 个测试。
- `cargo build --release`：通过。
- 本地运行验证：首个命中后进程仍在继续运行时，`result.jsonl` 已经包含 1 条已 flush 的 JSONL 记录。
