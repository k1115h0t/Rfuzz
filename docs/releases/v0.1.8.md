## v0.1.8

### English

#### Added
- Add `-dry-run` and `-explain` to print an execution plan without sending network requests, including request count, wordlist sizes, scheduling, output paths, response body limits, and the first rendered request.
- Add `-request-dry-run` for raw request workflows so operators can inspect the final rendered HTTP request before sending traffic.
- Add bounded response body controls: `-ignore-body`, `-max-body`, and `-body-preview`.
- Add end-of-run summaries with total, matched, filtered, error, and skipped counts, top error categories, top response signatures, output paths, and stop-on-match trigger status.
- Add `-summary-json` to persist the run summary as JSON.

#### Changed
- Recalculate `Content-Length` after raw request/body templates are rendered, avoiding stale body lengths when placeholders change the request body.
- Validate raw request `Host` handling for relative request lines and return a clear error when it is missing.
- Preserve the observed HTTP response version in raw response output instead of always rendering `HTTP/1.1`.
- Validate encoder keywords before scanning and warn when a wordlist keyword is not used by any request template.
- Treat Windows paths such as `C:\wordlists\dirs.txt` as normal wordlist paths instead of misreading the drive colon as a keyword separator.
- Bump the package version to `0.1.8`.

#### Verification
- `cargo fmt --all -- --check`: passed.
- `cargo clippy --all-targets -- -D warnings`: passed.
- `cargo test --all --locked`: passed, 75 tests.

### 中文

#### 新增
- 新增 `-dry-run` 和 `-explain`，在不发送网络请求的情况下输出执行计划，包括预计请求数、字典大小、调度方式、输出路径、响应 body 限制和首个渲染后的最终请求。
- 新增 `-request-dry-run`，方便 raw request 场景先检查最终渲染的 HTTP 请求，再决定是否真正发送流量。
- 新增响应 body 控制参数：`-ignore-body`、`-max-body`、`-body-preview`。
- 新增任务结束摘要，展示 total、matched、filtered、error、skipped、主要错误分类、高频响应签名、输出路径，以及 stop-on-match 是否实际触发。
- 新增 `-summary-json`，可将任务摘要保存为 JSON。

#### 变更
- raw request/body 模板渲染后会自动重算 `Content-Length`，避免 placeholder 改变 body 长度后仍发送旧长度。
- 相对路径 raw request 会校验 `Host`，缺失时给出清晰错误。
- raw response 输出会保留实际观测到的 HTTP 版本，而不是固定写成 `HTTP/1.1`。
- 扫描前校验 encoder keyword 是否存在，并在 wordlist keyword 未被任何请求模板使用时给出 warning。
- Windows 路径（如 `C:\wordlists\dirs.txt`）会按普通字典路径处理，不再把盘符冒号误解析成 keyword 分隔符。
- 将包版本提升到 `0.1.8`。

#### 验证
- `cargo fmt --all -- --check`：通过。
- `cargo clippy --all-targets -- -D warnings`：通过。
- `cargo test --all --locked`：通过，75 个测试。
