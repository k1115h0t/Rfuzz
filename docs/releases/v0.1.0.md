## v0.1.0

### Added
- Add editable release notes under `docs/releases/`.
- Update the GitHub Release workflow to read `docs/releases/${GITHUB_REF_NAME}.md`.
- Require release notes to exist before publishing a tag, so releases no longer fall back to generated notes.

### Performance
- Lazily build raw HTTP responses only when regex matching, raw output, or replay needs them.
- Cache the HTML title extraction regex with `OnceLock`.
- Delay title extraction until a response is actually emitted.
- Stop flushing console, JSONL, and CSV output after every matched record; writers now flush at the end of a run.
- Throttle progress bar rendering to reduce per-response locking and formatting overhead.
- Avoid cloning full rendered requests before sending HTTP requests.
- Reduce small per-case allocations in clusterbomb and rotate-window input generation.
- Avoid cloning the full wordlist set for every precheck task.

### Changed
- Keep regex matchers working against the complete raw response while skipping raw response construction for non-regex match/filter paths.
- Make URL space normalization cheaper for URLs that do not contain spaces.
