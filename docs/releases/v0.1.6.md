## v0.1.6

### Added
- Add `-precheck-attempts` / `--precheck-attempts` to configure target precheck round count.
- Add `README_CN.md` and make the main `README.md` English-first with a link to the Chinese documentation on the first line.

### Changed
- Run target precheck retries by rounds across all pending targets, for example `1,2,3,1,2,3`, instead of retrying each target consecutively.
- Keep `-precheck-report-only` as a reporting-only mode that does not skip failed target payloads.
- Bump the package version to `0.1.6`.

- `cargo fmt --check`: passed.
- `cargo test`: 66 passed.
