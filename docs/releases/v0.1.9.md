## v0.1.9

### English

#### Fixed
- Fix ordered clusterbomb scheduling so `-order` no longer implicitly switches to rotate-window ordering when `-precheck-key`, `-target-key`, or `-stop-scope` is present. Rotate-window ordering now only applies when `-schedule rotate-window` is explicitly selected.
- Fix precheck URL rendering so precheck applies the same `-enc` encoder chain and URL space normalization as normal requests. This prevents precheck from probing one URL while the main run would send another.
- Preserve CRLF line endings inside Burp raw request bodies when parsing text raw request files.
- Reject non-finite delay values such as `NaN` and `inf` instead of letting `Duration::from_secs_f64` panic.
- Reject incomplete client certificate configuration: `-cc` and `-ck` must now be provided together.
- Reject invalid raw request protocols early: `-request-proto` now only accepts `http` or `https`.

#### Changed
- Improve the invalid wordlist keyword error so paths containing `:` are easier to diagnose and can be fixed by passing an explicit keyword such as `:FUZZ`.
- Clarify stop-on-match semantics in the documentation: once a scope reaches the threshold, `rfuzz` stops scheduling new requests for that scope, but requests already in flight are not cancelled.
- Clarify raw request support in the documentation: text raw request bodies preserve CRLF, while binary body preservation is not guaranteed by the current text-template parser.
- Bump the package version to `0.1.9`.

#### Verification
- `cargo fmt --check`: passed.
- `cargo test --all --locked`: passed, 83 tests.
- `cargo clippy --all-targets -- -D warnings`: passed.
- `cargo build --release`: passed.

### 中文

#### 修复
- 修复 ordered clusterbomb 调度：`-order` 不会再因为存在 `-precheck-key`、`-target-key` 或 `-stop-scope` 而隐式切换成 rotate-window 顺序。只有显式使用 `-schedule rotate-window` 时才会进入 rotate-window。
- 修复 precheck URL 渲染路径：预检查现在会和真实请求一样应用 `-enc` 编码链和 URL 空格归一化，避免“precheck 探测的是 A，主任务发送的是 B”。
- 解析 Burp raw request 文本文件时，保留 body 内部的 CRLF 换行。
- 拒绝 `NaN`、`inf` 等非有限 delay 值，避免 `Duration::from_secs_f64` panic。
- 拒绝不完整的客户端证书配置：`-cc` 和 `-ck` 现在必须成对提供。
- 提前拒绝非法 raw request 协议：`-request-proto` 现在只接受 `http` 或 `https`。

#### 变更
- 改进非法 wordlist keyword 的报错，让包含 `:` 的路径更容易诊断，并提示可显式追加 `:FUZZ`。
- 文档明确 stop-on-match 语义：某个 scope 达到阈值后，`rfuzz` 会停止调度新的同 scope 请求，但不会取消已经在飞的请求。
- 文档明确 raw request 支持边界：文本 raw request body 会保留 CRLF，但当前文本模板解析器不保证二进制 body 保真。
- 将包版本提升到 `0.1.9`。

#### 验证
- `cargo fmt --check`：通过。
- `cargo test --all --locked`：通过，83 个测试。
- `cargo clippy --all-targets -- -D warnings`：通过。
- `cargo build --release`：通过。
