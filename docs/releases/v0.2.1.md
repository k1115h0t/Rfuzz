## v0.2.1

### English

#### Added
- Add a dedicated precheck progress bar on `stderr`. Each retry round reports its round number, completed target probes, reachable targets, current-round unreachable targets, and ETA.
- Make `-no-progress` disable both the precheck progress bar and the main scan progress bar.
- Add regression coverage for precheck retry progress, target deduplication, case-insensitive HTTP schemes, rate-limited HEAD-to-GET fallback, zero-copy body conversion, borrowed matcher text, and the no-encoder fast path.

#### Fixed
- Enforce the global `-rate` limit for every explicit precheck HTTP request. HEAD requests, GET fallbacks, and HTTPS/HTTP protocol candidates now consume separate rate-limit permits.
- Share one rate limiter across precheck and the main scan so the phase boundary cannot briefly exceed the configured request rate.
- Deduplicate identical precheck target values while preserving their first-seen order, avoiding redundant probes and inconsistent retries.
- Accept case-insensitive `HTTP://` and `HTTPS://` schemes during precheck instead of incorrectly adding another protocol prefix.
- Reject `-precheck-key` configurations where the selected keyword is not used by the `-u` URL template, instead of silently probing the same URL repeatedly.
- Clear the precheck progress bar before printing final precheck errors, preventing error lines from corrupting the dynamic display.

#### Performance and memory
- Reuse the downloaded response buffer directly as a `String` for valid UTF-8 bodies. Binary and invalid UTF-8 responses keep the previous lossy-decoding behavior.
- Borrow cached matcher text instead of cloning the raw response for each regex evaluation.
- Share immutable request and encoder configuration across workers with `Arc` instead of deep-cloning it for every spawned task.
- Move `InputCase` and response signatures through the worker pipeline instead of cloning their maps, payload strings, display strings, and metadata.
- Skip cloning the payload map entirely when no encoders are configured by using a borrowed fast path.
- Replace precheck's deep copy of every wordlist value with a lightweight shared context containing only keywords, the URL template, encoders, client, and limiter.
- Remove unused direct dependencies (`governor`, `thiserror`, and `bytes`) and prune their no-longer-needed dependency graph entries.

#### Benchmark
- Local loopback benchmark: 400 responses × 1 MiB, `-t 100`, body-regex matching, five interleaved baseline/optimized runs.
- Median peak working set: `149.88 MiB` → `131.14 MiB` (`12.5%` lower).
- Median completion time: `645.2 ms` → `584.7 ms` (`10.4%` faster).
- Concurrency, queue capacity, connection reuse, scheduling, matcher behavior, and response limits were unchanged for the benchmark.

#### Changed
- Document that precheck has a separate per-round progress bar and that explicit fallback/protocol requests are individually rate limited.
- Update the English and Chinese version badges to `0.2.1`.
- Bump the package version to `0.2.1`.

#### Verification

- `cargo test`: passed, 95 tests.
- `cargo test --release`: passed, 95 tests.
- `cargo clippy --all-targets -- -D warnings`: passed.
- `cargo build --release`: passed.
- `git diff --check`: passed.

### 中文

#### 新增
- 新增独立的 precheck `stderr` 进度条。每轮重试都会显示轮次、已完成目标探测数、可达目标数、本轮不可达目标数和 ETA。
- `-no-progress` 现在会同时关闭 precheck 进度条和主扫描进度条。
- 新增 precheck 重试进度、目标去重、HTTP scheme 大小写、HEAD→GET 回退限速、body 零复制转换、matcher 借用以及无编码器快速路径的回归测试。

#### 修复
- 对每个显式 precheck HTTP 请求执行全局 `-rate` 限速。HEAD、GET fallback 以及 HTTPS/HTTP 协议候选现在都会分别获取限速许可。
- precheck 与主扫描共享同一个限速器，避免阶段切换瞬间超过配置的请求速率。
- 对相同的 precheck 目标值进行稳定去重，保留首次出现顺序，避免重复探测和重试结果不一致。
- precheck 正确识别大小写不敏感的 `HTTP://` 和 `HTTPS://`，不再错误地重复添加协议前缀。
- 当 `-precheck-key` 没有出现在 `-u` URL 模板中时立即报错，避免静默重复探测同一个 URL。
- 在打印最终 precheck 错误前清除动态进度条，避免错误行破坏进度显示。

#### 性能与内存
- 对有效 UTF-8 响应直接复用下载缓冲区作为 `String`；二进制和非法 UTF-8 响应继续保持原有的 lossy 解码行为。
- matcher 直接借用缓存文本，不再为每次正则判断复制 raw response。
- 使用 `Arc` 在 worker 之间共享不可变请求配置和编码器配置，不再为每个任务深拷贝。
- 在 worker 流程中直接移动 `InputCase` 和响应签名，减少 payload map、字符串、显示文本和元数据复制。
- 未配置编码器时直接借用 payload map，完全跳过逐请求 map clone。
- precheck 不再深拷贝所有字典值，改为共享只包含 keyword、URL 模板、编码器、客户端和限速器的轻量上下文。
- 移除未使用的直接依赖 `governor`、`thiserror` 和 `bytes`，并清理对应的无用传递依赖。

#### 压测
- 本机回环压测：400 个 1 MiB 响应、`-t 100`、body 正则匹配、优化前后各 5 轮交叉运行。
- 峰值工作集中位数：`149.88 MiB` → `131.14 MiB`，下降 `12.5%`。
- 完成时间中位数：`645.2 ms` → `584.7 ms`，缩短 `10.4%`。
- 压测期间并发度、队列容量、连接复用、调度方式、matcher 行为和响应限制均未改变。

#### 变更
- 文档补充 precheck 独立逐轮进度条，以及显式 fallback/协议候选请求分别限速的行为。
- 将中英文版本徽章更新为 `0.2.1`。
- 将包版本提升到 `0.2.1`。
