## v0.1.4

### Fixed
- Rebuild raw HTTP response headers with canonical casing before regex matching and raw output. Header matchers such as `-mr "Set-Cookie: session_id="` now work even when the HTTP client stores response header names internally as lowercase.
- Add regression coverage for raw response header rendering, including `Set-Cookie` matching.

### Documentation
- Sanitize README login-fuzzing examples to use generic target lists, cookie names, form fields, output files, and precheck targets.
- Remove product-specific names and real-looking infrastructure details from public examples.
